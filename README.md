## 주의

- API 키·토큰·비밀번호는 저장소에 넣지 않았다. 본문 안내대로 환경 변수나 `.env`로 넘긴다. Docker 구성의 비밀번호는 로컬 실습용 예시 값이다.
- 모델 이름·요금·제품 화면은 책의 확인 일자 이후 바뀔 수 있다.
- 이 책과 저장소는 본문에 나오는 제품·서비스의 회사와 관련이 없는 비공식 자료다.
